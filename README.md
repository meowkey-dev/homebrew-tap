# meowkey-dev/tap

Homebrew tap for [Analog](https://github.com/meowkey-dev/analog), a shared canvas
for one human and their agents.

```bash
brew install meowkey-dev/tap/analog
```

Installs `analog`, `analog-server` and `analog-mcp`. `Formula/analog.rb` is
regenerated on each release by `scripts/bump-tap.sh` in the main repo; pushes here
run the formula's install and test on macOS and Linux.
